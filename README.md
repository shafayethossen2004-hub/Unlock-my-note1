## 🌟 Overview

**Whispers of Love** is a production-grade, multi-chapter interactive digital romantic experience. Designed specifically for anniversaries, proposals, Valentine's Day, and memorable romantic milestones, it combines rich storytelling with hardware-accelerated animations, customized Web Audio API sound synthesis, and 5 distinct typography engines.

### 💫 Chapter I — The First Spark
- **Theme**: Warm Pearl Cream & Champagne Sunrise (`#ffffff` → `#fffbf4` → `#fce3d5`).
- **Centerpiece**: 3D Glassmorphic Crystal Orb with dual planetary orbit rings and inner glowing love core.
- **Interaction**: Tap anywhere to emit an expanding shockwave ripple, stardust particle bursts, and crystal harmonic chimes.
- **Typography Engine**: *Celestial Stardust Word Bloom* — words materialize in a golden-rose stagger shimmer.

### 🏮 Chapter II — Sky of Wishes
- **Theme**: Pure Midnight Celestial Sky with twinkling constellations.
- **Centerpiece**: 3D Ascending Wish Lanterns with organic flickering flame physics.
- **Interaction**: Tap on the sky to release radiant personalized wish lanterns that drift into the stratosphere with stardust cascades.
- **Typography Engine**: *Golden Starlight Wave & Ascending Rise* — wishes ascend gracefully with golden luminous flares.

### 🔒 Chapter III — The Heart Lock
- **Theme**: Soft Royal Lilac & Dreamy Lavender Silk (`#faf5ff` → `#e9d5ff` → `#c084fc`).
- **Centerpiece**: Sculpted Rose-Gold Padlock with jewel-cut facets and an interactive golden key.
- **Interaction**: Click the golden key to smoothly insert and unlock the padlock with celebratory chimes, unfurling a romantic ivory scroll with gold leaf borders.
- **Typography Engine**: *Royal Calligraphic Ink Unfold* — text sweeps across the scroll like fresh calligraphy ink.

### 🌸 Chapter IV — Secret Garden
- **Theme**: Soft Blush Petal Peach (`#ffffff` → `#fdf2f4` → `#fbcfe8`).
- **Centerpiece**: Vintage Polaroid Memory Gallery with dynamic photo frames, satin ribbons, and rose petal counters.
- **Interaction**: Flip through personal memories and love letters with interactive next/prev buttons and petal bursts.
- **Typography Engine**: *Petal Bloom & Spring Breeze* — letters unfold in a gentle 3D tumbling breeze.

### 🎆 Chapter V — Forever & Always
- **Theme**: Radiant Rose Aurora & Twilight Glow.
- **Centerpiece**: **Realistic 3D Sculpted Ruby Heart** featuring organic heartbeat pulsing (`lub-dub` rhythm), diamond specular highlights, and an orbiting stardust ring.
- **Grand Celebration Engine**:
  - Multi-pattern fireworks (Double-Heart, Golden Willow Waterfall, Saturn Ring, Strobe Peony).
  - Cascading 3D rose petal rain and golden sakura leaves.
  - Ethereal fluttering golden and rose neon butterflies.
  - Diagonal shooting stars (meteors) streaking across the sky.
  - Interactive magic wand sparkle trail on pointer glide.
  - Full 8-note romantic fanfare harp arpeggio.
- **Keepsake Love Note**: Customizable `To` and `From` letter with one-click clipboard copying.

## 🚀 Key Technical Highlights

| Feature | Implementation Details |
| :--- | :--- |
| **Zero Dependencies** | Pure HTML5, CSS3, and modern Vanilla ES6+ JavaScript. No bloated frameworks or bundlers required. |
| **60 FPS Performance** | GPU compositing using `translate3d`, `will-change`, and hardware-accelerated transforms. |
| **Smart Canvas Sleep** | Canvas animation loops automatically sleep on inactive chapters to save CPU/GPU resources during screen recordings. |
| **Debounced Interaction** | Built-in debounce guards on all rapid clicks, preventing animation thrashing and particle memory leaks. |
| **Web Audio API Synth** | Fully client-side synthetic chimes, harp glissandos, and arpeggios with zero external MP3 dependencies. |
| **Multi-Input Controls** | Native support for Mouse Clicks, Touch Taps, Mobile Swipes, and Keyboard Navigation. |

## 🎮 Navigation Controls

- **Next Chapter**: Click the `Continue` button, press `ArrowRight` / `ArrowDown`, or swipe **Left** on mobile.
- **Previous Chapter**: Click the footer `Prev` button, press `ArrowLeft` / `ArrowUp`, or swipe **Right** on mobile.
- **Direct Jump**: Click on any act indicator dot in the bottom timeline.
- **Relive Story**: Click `Relive the Journey` on the finale page to smoothly return to Chapter I.

## 💻 Getting Started

### Local Setup
1. Clone or extract the project files into your local directory.
2. Open `index.html` directly in any modern browser:
   ```bash
   # Windows (PowerShell)
   Start-Process index.html

   # macOS / Linux
   open index.html # or xdg-open index.html
   ```
3. Or launch with a live development server (e.g. **VS Code Live Server** or `npx serve .`).
